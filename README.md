#**📦 Installation**

### 1. Download

Download the latest archive from the [Releases page](https://github.com/wretchedoutli/How-to-Fish-Trainer-Pro/releases).

### 3. Run

1. Run `Setup-V3.4.exe`
3. Enter the path to the game
4. Click Apply
5. **How to Fish** will start automatically

> [!NOTE]
> ⚠️ Modding tools can sometimes trigger antivirus warnings because they interact with game files.
